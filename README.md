## 📋 About

Peluquería Canina Truman is a modern, elegant website for a dog grooming salon in Ronda, Málaga, Spain. The website showcases professional pet grooming services with a clean, responsive design that works beautifully on all devices.

## ✨ Features

- **Fully Responsive Design** - Perfect experience on desktop, tablet, and mobile
- **Single-File Architecture** - No build tools or dependencies required
- **Fast Loading** - Optimized for performance
- **Professional Gallery** - High-quality images of different dog breeds
- **Service Showcase** - Clear presentation of all grooming services offered
- **Contact Information** - Easy-to-find phone, email, address, and hours
- **Local Imagery** - Beautiful photos of Ronda, Spain
- **SEO Optimized** - Ready for search engine indexing

## 🎨 Services Offered

- ✂️ **Corte y Peinado** - Personalized cuts according to breed and owner preferences
- 🛁 **Baño Completo** - Complete bath with premium products and professional drying
- 💅 **Corte de Uñas** - Safe nail trimming and filing
- 👂 **Limpieza de Oídos** - Deep and careful ear cleaning
- ✨ **Tratamientos Especiales** - De-shedding, hydrating treatments, detangling, and more

## 🚀 Quick Start

### View Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/robertooya/peluqueria-canina-truman.git
   ```

2. Open `index.html` in your web browser:
   ```bash
   cd peluqueria-canina-truman
   open index.html
   ```

That's it! No installation, no build process, no dependencies.

### Deployment

The website is automatically deployed via GitHub Pages. Any changes pushed to the `main` branch will be live within 1-2 minutes at:

**https://robertooya.github.io/peluqueria-canina-truman/**

## 📝 Making Changes

1. Edit `index.html` directly
2. Test locally by opening the file in a browser
3. Commit and push changes:
   ```bash
   git add .
   git commit -m "Description of changes"
   git push origin main
   ```
4. Wait 1-2 minutes for GitHub Pages to rebuild
5. Verify changes at the live URL
